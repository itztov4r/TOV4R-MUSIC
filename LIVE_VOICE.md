# Experimental live microphone mode
/tl3 joins the configured guild owner's solo voice channel. It listens only to that owner after explicit command and notice, detects a short pause locally, sends the utterance to OpenAI, plays the synthetic answer, then listens again. /hbt cancels the session. Other members entering or owner leaving stops it. No stored audio, no server actions, five-minute session, no continuous context yet.
Disabled by default. Before enabling TOV4R_LIVE_VOICE=1, review and pin a DAVE-compatible discord.ext.voice_recv distribution (upstream PR #54/#65 are experimental), install in a private staging environment, verify audio receive/stop/privacy and OpenAI model configuration. Do not disable DAVE or use a user token. The existing /voiceai remains independent.
